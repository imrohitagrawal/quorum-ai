**What the verdicts mean.**
- **TESTED**: in place, and a named test fails without it.
- **MEASURED**: the session checked production directly with a free, read-only request.
- **CODE-ONLY**: the code does it, and no test was found that would fail without it.
- **PARTIAL**: some of the item is in place; the Evidence says what is missing.
- **NOT IN PLACE**: missing.
- **UNKNOWN**: reading the code could not settle it; the Evidence names the check that would.
- **N/A**: the app has no such feature; the Evidence says why.

The Row column names the board row (`docs/65-open-work.md`) that closes the gap. "—" means no gap
was found. "advisory" means the gap is recorded here and on no row. "owner" means it needs the owner's
account or money. "unknown" means only a check against Fly could settle it. For an N/A item, a row
named there is related work, not a gap in the item. A verdict the session changed from the agent's
says so at the start of its Evidence.
